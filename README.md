# GazeLoom

Monitors eye-tracking data for software developers, detecting user behavior and performance metrics.

GazeLoom is aimed at developers who need a straightforward, dependable solution.

**Highlights**

- Monitors eye-tracking data for software
- developers, detecting user behavior and
- performance metrics

## Technology Stack

- javascript
- Modular architecture
- CI-ready (GitHub Actions)

## Installation

1. Clone the repository: `git clone https://github.com/karanjamoses/GazeLoom.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

GazeLoom is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
